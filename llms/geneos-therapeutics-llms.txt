# Geneos Therapeutics

> Clinical-stage (Phase 2b) biotherapeutics company in Philadelphia, Pennsylvania developing DNA-based personalized immunotherapies for cancer (PICs). Its GT-EPIC neoantigen-targeting platform sequences a patient's tumor, identifies targetable neoantigens, and encodes up to roughly 40 of them into a synthetic DNA plasmid drug product delivered intradermally with a plasmid-encoded IL-12 adjuvant and CELLECTRA electroporation. Spun out of Inovio Pharmaceuticals under an exclusive platform license. Clinical work to date in hepatocellular carcinoma (HCC) and glioblastoma (GBM).

## API surface

Geneos Therapeutics publishes NO public API. As of 2026-08-16 there is no developer portal,
no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK in any public package registry,
no GitHub organization, no MCP server and no A2A agent card. The corporate site runs WordPress;
its /wp-json/ endpoint is CMS infrastructure, not a published product API, and is not catalogued
as one. This is a therapeutics developer, not a software vendor — the absence is expected and
is not a defect.
